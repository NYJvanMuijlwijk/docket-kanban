# Impeccable Design Context

## Design Context

### Users
Solo developer using this as a personal task management tool and Flutter portfolio piece. Mobile is the primary platform; web exists for testing and demo purposes only. The user is the only audience — no collaboration features yet.

### Brand Personality
Minimal, focused, calm. A zen productivity tool that stays out of the way. Developer-grade — precision without pretension.

### Aesthetic Direction
- **References:** Linear (dark palette, developer-focused hierarchy), Vercel Dashboard (restrained color, monospace touches), Raycast and Warp (subtle opacity/translucency layers for depth)
- **Anti-references:** Jira/Trello (cluttered enterprise chrome), Monday.com/Asana (too colorful, too playful, too much visual noise)
- **Theme:** Dark-mode-first (`ThemeMode.dark` hardcoded). Warm amber accent (`#D4A054`) against near-black surfaces. Depth via subtle surface layering (7-step opacity ramp from `#0F1114` to `#2E343B`), not drop shadows or heavy borders.

### Implemented Color System
- **Accent:** `#D4A054` (warm amber) — actions, focus, FAB
- **Accent Dim:** `#8B6B3A` — secondary elements, badges
- **Surfaces (darkest to lightest):**
  - `#0F1114` scaffold background
  - `#151719` base surface
  - `#191C1F` surface container lowest
  - `#1C1F23` surface container low (column backgrounds)
  - `#22262B` surface container
  - `#282D33` surface container high (card backgrounds)
  - `#2E343B` surface container highest
- **Text:** `#E2E4E8` primary, `#8B919A` secondary
- **Borders:** `#3A4049` outline, `#2A2F36` outline variant
- **Error:** `#E5736E` warm red
- **Column accents** (6-color rotation): steel blue, sage green, warm clay, muted lavender, dusty rose, seafoam

### Typography
- **Font:** Plus Jakarta Sans (geometric humanist, more character than Inter)
- **Scale:** Major-third (~1.2x): 11 / 13 / 16 / 20 / 24 / 28
- **Headings:** Bold (w700), tight negative letter-spacing for developer-tool density
- **Body:** Regular (w400), elevated line-height (1.45-1.5) for dark-mode readability
- **Column headers:** Uppercase with wide tracking (`titleMedium`: 11px, w700, +1.2 tracking)
- **Timestamps:** Tabular figures (`labelSmall`: 11px, w500, +0.4 tracking)

### Spacing & Layout
- **Border radius:** 12px (columns, cards), 8px (inputs, snackbars)
- **Column margin:** 6px horizontal, 12px vertical
- **Card padding:** 16px horizontal, 10px vertical
- **Card accent border:** 3px left (column color)
- **Compact breakpoint:** 600px
- **Column width:** 220-400px fluid (min depends on breakpoint)
- **Sheet max width:** 500px, content max width: 800px
- **Responsive padding:** 16px compact, 24px tablet+

### Animation System
- **Entrance stagger:** 50ms per item, 300ms duration, easeOutCubic, fade + 12px slide. Max 8 items staggered.
- **Drag ghost:** 200ms height transition, easeInOut. Ghost at 40% opacity.
- **Drag feedback:** 1.04x scale, primary-tinted + dark dual shadows.
- **Column hover:** 200ms color transition to 14% accent blend.
- **Shimmer loading:** 1500ms repeating gradient, synchronized across blocks.
- **All animations respect `MediaQuery.disableAnimationsOf` for reduce-motion.**

### Design Principles
1. **Content over chrome** — UI elements recede; cards and columns are the focus.
2. **Depth through surface layering** — 7-step surface ramp creates hierarchy. Shadows reserved for drag elevation only.
3. **Restrained color** — Warm amber accent used sparingly for actions/state. Column accents are muted pastels. Everything else is neutral.
4. **Let it breathe** — Generous spacing and padding. Resist the urge to fill empty space.
5. **Developer-grade polish** — Smooth animations, crisp typography, haptic feedback. Feels like a tool built by a developer for developers.
6. **Mobile-first** — Touch targets, long-press drag, responsive column sizing. Web is secondary.
7. **Reduce-motion safe** — Every animation checks accessibility preference. No animation is mandatory for function.

### Accessibility
- Standard Material 3 contrast ratios and touch targets
- All animations respect reduce-motion preference
- Keyboard/semantics gaps identified in audit (to be addressed)
